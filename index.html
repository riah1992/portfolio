01 ABOUT

보이는 화면은 정확하게,
보이지 않는 구조는 단단하게.

2021년 12월부터 공공기관·교육 서비스 13개 프로젝트의 UI를 퍼블리싱했습니다. 전자정부프레임워크 기반 홈페이지와 관리자 화면을 시안과 어긋나지 않게 구현하고, 웹 표준·웹 접근성·반응형·크로스 브라우징 기준을 지키는 마크업을 기본으로 삼았습니다.

구축에서 끝나지 않고 운영 중인 기관 사이트의 수정 요청까지 맡으며, 다른 사람이 고쳐도 깨지지 않는 구조를 고민해 왔습니다. 2026년부터는 SI사업팀에서 JSP·Thymeleaf 템플릿과 데이터 흐름까지 경험하고 있습니다. 최근에는 AI 도구를 활용해 기획, 디자인, 퍼블리싱, 개발을 한 흐름으로 진행하고 있습니다.

  • 기획·개발과의 소통

    기획팀과는 화면 의도와 예외 상황을, 개발팀과는 마크업 구조와 데이터가 들어갈 자리를 먼저 맞추고 작업을 시작합니다.

  • 다음 사람을 생각하는 작업

    내 결과물을 받는 부서가 무엇을 편하게 여길지 늘 먼저 생각합니다. 개발자가 바로 붙일 수 있는 구조를 기준으로 삼습니다.

  • 운영까지 책임지는 태도

    오픈 이후 유지보수 요청까지 고려해, 누가 수정해도 다른 화면이 깨지지 않도록 구조를 정리합니다.

04 HOW I PUBLISH

퍼블리싱에서
놓치지 않는 기준.

  1. 01

    웹 표준 · 시맨틱 마크업

    header·nav·main·section 같은 구조 태그와 제목 위계를 먼저 잡고 스타일을 입힙니다. 화면이 바뀌어도 문서 구조는 흔들리지 않게 합니다.

  2. 02

    웹 접근성

    공공기관 사이트 기준에 맞춰 대체 텍스트, 건너뛰기 링크, 키보드 초점, 명도 대비, 표·폼의 레이블을 챙깁니다.

  3. 03

    반응형 · 디바이스 대응

    PC 관리자와 모바일 사용자 화면이 함께 있는 서비스를 오래 맡으며, 같은 컴포넌트가 화면 폭과 사용자 유형에 따라 자연스럽게 바뀌도록 설계했습니다.

  4. 04

    크로스 브라우징

    공공 사이트 특성상 다양한 브라우저와 해상도에서 화면이 같게 보이도록 점검합니다.

  5. 05

    운영을 견디는 CSS 구조

    CMS 템플릿과 공통 위젯처럼 여러 사이트에서 재사용되는 화면은 영역별로 클래스를 나눠, 다른 사람이 고쳐도 다른 곳이 깨지지 않게 합니다.

  6. 06

    개발과의 연결

    JSP·Thymeleaf 템플릿에 직접 마크업을 붙이고 데이터 흐름까지 이해하기 때문에, 퍼블리싱 결과물이 개발 단계에서 다시 바뀌는 일을 줄입니다.

01통통통 · css/mngr_component.css

통통통 · CSS 변수와 상태 클래스로 만든 공통 컴포넌트

수백 개의 화면이 같은 규칙을 쓰도록 색상과 글자 크기를 CSS 변수로 모았습니다. 출결·수강·원생 상태는 opt- 클래스 하나로 색이 정해지고, 작은 모바일에서는 변수 값만 바꿔 화면 전체의 글자 크기를 조정합니다.

:root {
  /* Color */
  --pc-bora-7: #5647B3;
  --pc-bora-8: #9d93c1;
  --pc-red: #dd346d;
  /* Font */
  --pc-text-h1: 36px;
  --pc-text-h2: 24px;
}

/* 옵션 상태: 상태 이름만 붙이면 색이 정해짐 */
[class^="opt-"] { font-weight: var(--text-medium); font-size: var(--pc-fs13); }

/* 출결 상태 */
.opt-attend { color: var(--pc-bora-7)!important; }  /* 출석 */
.opt-absent { color: var(--pc-red)!important; }     /* 결석 */
.opt-late   { color: var(--pc-bora-6)!important; }  /* 지각 */

/* 수강 상태 */
.opt-end    { color: var(--pc-red)!important; }     /* 종강 */
.opt-course { color: var(--pc-bora-7)!important; }  /* 수강 */
@media only screen and (max-width: 767px) {
  .fs14 { font-size: var(--m-fs14)!important; }
  .fs15 { font-size: var(--m-fs15)!important; }
}

/* 작은 기기에서는 변수 값만 바꿔 전체 글자 크기를 조정 */
@media only screen and (max-width: 375px) {
  :root { --m-fs15: 14px; --m-fs14: 13px; }
  .m-academy-mngr-Wrap .m-graph-box { flex-wrap: wrap; flex-direction: column; }
}
@media only screen and (max-width: 300px) {
  :root { --m-fs13: 12px; }
  .m-academy-mngr-Wrap .label-set select { width: 100%; }
  .m-academy-mngr-Wrap .check-list.col3 li { width: 49%; }
}

직접 정한 디자인 토큰과 버튼 상태 규칙을 문서로 만들어 AI 코딩 도구에 전달했습니다. 접근성 속성까지 규칙에 넣어 구현 결과가 디자인과 어긋나지 않게 했습니다.

:root {
  --tb-border: #E3E6EB;     /* 툴바 테두리, 구분선 */
  --btn-size: 32px;         /* 아이콘 버튼 32×32 */
  --btn-radius: 7px;
  --icon: #3F4654;          /* 기본 */
  --bg-hover: #F1F3F6;
  --icon-active: #1A56DB;   /* 적용됨 (예: 굵게 켜짐) */
  --bg-active: #E8F0FE;
  --icon-disabled: #B4BAC4;
  --focus-ring: #1A56DB;    /* 2px, offset 1px, :focus-visible */
}

/* 상태          배경            아이콘 색
   기본          투명            --icon
   호버          --bg-hover      --icon-hover
   활성(적용됨)  --bg-active     --icon-active
   포커스        2px 링 --focus-ring
   비활성        투명            --icon-disabled
   - 토글 버튼(B/I/U/S)은 aria-pressed
   - 아이콘 전용 버튼은 aria-label 필수, SVG는 aria-hidden="true" */

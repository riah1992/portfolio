# 주리아 포트폴리오

공공기관·교육 서비스 13개 프로젝트를 웹 표준·웹 접근성·반응형으로 구축하고 운영해 온 5년차 웹 퍼블리셔의 정적 포트폴리오입니다.

## 구성

- 소개: 경력 요약 숫자(5년차 · 퍼블리싱 13건 · 공공·교육 9건)와 웹 퍼블리셔 소개
- 대표 퍼블리싱: 통통통(PC·학원용·학부모용 모바일), 서울과기대 산학협력단(시안 vs 결과), 경기도교육복지종합센터(PC·모바일), CMS 메인 템플릿, 남양고진공
- 그 밖의 퍼블리싱: 훈장마을, 오산교육재단, 드론정보포털, KOTRA 서울푸드, 유지보수 4건
- 작업 원칙: 웹 표준, 접근성, 반응형, 크로스 브라우징, CSS 구조, 개발 연계
- 개발 경험: 위즈샵 관리자 메뉴, 패들릿 게시판, 위즈빌더 고도화, 위젯 모바일 비노출
- 경력 · 기술 · 자격·교육·학력

화면 캡처는 `assets/pub/`에 있으며, 마우스를 올리면 페이지 전체가 스크롤됩니다.
